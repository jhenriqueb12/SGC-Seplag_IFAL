# Backend — SGC

API REST em Node.js + Express.

## Executar

```bash
cp .env.example .env
npm install
npm run dev
```

Health check: `GET http://localhost:3000/api/health`.

A conexão PostgreSQL e os módulos de autenticação/contratos serão implementados nas próximas tarefas. Não coloque credenciais reais no repositório.
